# VoxSynth

Формантный синтезатор русской речи. Превращает русский текст в звук: голосовой источник (импульс гортани) проходит через каскад формантных резонаторов, шумовые согласные формируются отдельным полосовым фильтром. Работает на чистом C, без внешних зависимостей, и легко встраивается в iOS через готовую Objective-C обёртку.

## Возможности

- **Формантный синтез** — три форманты (F1–F3) с интерполяцией переходов между звуками, импульс Розенберга в роли голосового источника.
- **Русская фонетика** — побуквенное преобразование текста в сегменты: гласные с редукцией (аканье/иканье), согласные всех типов (взрывы, фрикативные, аффрикаты, носовые, боковые, дрожащие, скользящие).
- **Ударение** — словарь на ~500 словоформ + автоматическое определение по «ё» + резервное правило для незнакомых слов.
- **Ассимиляция по глухости/звонкости** — регрессивное оглушение/озвончение парных согласных, оглушение на конце слова.
- **Палатализация** — мягкость согласных перед е, ё, и, ю, я, ь и в исконно мягких (щ, ч, й).
- **Интонация** — плавное снижение тона по фразе.
- **Дрожание** — амплитудная модуляция для «р».
- **Потоковое воспроизведение на iOS** — AudioQueue играет предложение за предложением, речь начинается почти сразу, память не растёт под весь текст.
- **Скорость** — параметр темпа (1.0 — обычный, 1.3 — быстрее).

### FormantCore

Ядро синтеза. Резонатор — биквадратный фильтр, настроенный на частоту форманты и её полосу. Сегмент (`FCSegment`) описывает звук: форманты, основной тон, громкость голоса и шума, центр/полоса шума, глубину дрожания, длительность и время перехода.

```c
typedef struct {
    float f1, f2, f3;    // форманты, Гц
    float f0;            // основной тон, Гц
    float voiceAmp;      // громкость голоса 0..1
    float noiseAmp;      // громкость шума 0..~1
    float noiseF;        // центр полосы шума, Гц
    float noiseBw;       // ширина полосы шума, Гц
    float am;            // глубина дрожания (для «р»), 0..1
    float ms;            // длительность, мс
    float trans;         // время перехода формант, мс
} FCSegment;

size_t FCTotalSamples(const FCSegment *segs, size_t count, float sampleRate);
size_t FCRender(const FCSegment *segs, size_t count,
                int16_t *out, size_t capacity, float sampleRate);
```

Рендер выдаёт 16-бит моно PCM. Форманты между сегментами интерполируются, громкость — с коротким (8 мс) переходом, чтобы не щёлкало.

### Phonemes

Преобразует массив UTF-32 кодовых точек в массив сегментов. Для каждого слова: находит ударную гласную, применяет ассимиляцию по глухости/звонкости, выбирает форманты гласной с учётом позиции относительно ударения, обрабатывает мягкость согласных.

```c
size_t PHTextToSegments(const uint32_t *text, size_t n,
                        FCSegment *out, size_t cap, float speed);
```

Под капотом — таблица согласных (`kCons`) с локусом формант, параметрами шума и длительностью, и функция `vowelTarget`, реализующая редукцию: аканье (безударные о/а сближаются), иканье (безударные е/э тянутся к и), укорочение и приглушение остальных гласных.

### Stress

Словарь ударений в виде словоформ (не лемм — в русском ударение часто уходит при склонении/спряжении). Слова с «ё» в словарь не включены: «ё» почти всегда ударная и определяется автоматически.

```c
int STFindStress(const uint32_t *word, size_t len);
```

Возвращает номер гласной (1-based) или 0, если слово не найдено — тогда вызывающий код применяет резервное правило (по умолчанию — последняя гласная).

### iOS-обёртка

```objc
VoxSynth *synth = [VoxSynth shared];
synth.speed = 1.0f;

[synth speak:@"привет, как дела?"];   // потоковое воспроизведение
[synth stop];                          // немедленное прерывание

NSData *wav = [synth wavDataForText:@"привет"];  // WAV в памяти
```

`speak:` режет текст на предложения, синтезирует их в фоновой очереди и подкладывает в AudioQueue по мере готовности. Обрабатывает прерывания аудиосессии (звонок, будильник) — просто останавливает речь.

## Сборка и запуск (CLI)

```bash
cd VoxSynth
cc -O2 -o voxtest test_main.c FormantCore.c Phonemes.c Stress.c -lm
./voxtest "мама мыла раму" speech.wav 1.0
```

Аргументы: текст, имя WAV-файла, темп. Без аргументов синтезирует «мама мыла раму» в `speech.wav`.

## Подключение к iOS-проекту

1. Добавьте в проект все `.c`, `.h` и `.m` файлы из `VoxSynth/`.
2. Слинкуйте `AudioToolbox.framework` и `AVFoundation.framework`.
3. Включите ARC (обёртка написана под ARC).
4. Импортируйте `VoxSynth.h` и используйте `[VoxSynth shared]`.

## Ограничения

- **Побуквенное G2P**, не фонемное. Омографы («слова» — род. падеж или им. мн.) сведены к одному значению, отдельные ошибки ударения неизбежны.
- **Словарь ударений** покрывает частотную лексику; для остального — резервное правило на последний слог (частая, но не всегда верная эвристика).
- **Резонаторы F1–F3** — без F4/F5 и без учёта носового тракта как отдельного резонатора; носовые согласные смоделированы упрощённо.
- **AudioQueue-колбэк** может ненадолго заблокироваться, если синтез не успевает — осознанный компромисс ради простоты. На практике синтез в разы быстрее воспроизведения, ожидание почти всегда мгновенное.
- **Только русский** — таблицы и правила заточены под русскую фонетику.
